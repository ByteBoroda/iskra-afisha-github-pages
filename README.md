# Афиша · Искра Банк

Кликабельный прототип городской афиши для вымышленного банка. Каталог показывает события московской афиши на 7–15 ноября 2026 года.

## Что проверить

- На главной откройте «Вальс-бостон», выберите сеанс и места на схеме. В карточке Zivert · Big Club Show можно выбрать зону и количество билетов.
- Нажмите «Продолжить» и «Оплатить». На экране появится подтверждение, а заказ будет доступен в «Моих билетах». Демо-билет можно скачать как самостоятельный HTML-файл.
- На главной работают подборки, категории, фильтр по датам и поиск по названию или площадке. Избранное и заказы сохраняются в браузере.

На телефоне рекомендации на главной листаются свайпом, а вкладки доступны снизу. На этапах выбора билетов и оплаты основная кнопка закреплена внизу экрана. На узких экранах схему зала можно прокручивать по горизонтали.

## Исследование запуска

В разделе «Запуск» собраны партнерские кейсы банков, сравнение поставщиков, контакты, интерактивная доска Ганта и «Unit экономика». У Ганта два стрима: вайб-код с покупкой у оператора и команда разработки с собственным оформлением заказа. В командном плане инженерные задачи сокращены на 30%. Чтобы увидеть исходные сроки, выберите «Команда разработки» и отметьте «Показать план команды без LLM».

В «Unit экономике» формулы сопоставлены с файлом «Юнит-экономика_PS.xlsx». Базовые значения собраны из отраслевых ориентиров и допущений на 90 дней. Источники указаны у параметров. Ползунки идут от нуля до удвоенного базового значения. Вручную можно ввести число выше этого диапазона.

## GitHub Pages

1. Распакуйте архив и загрузите его содержимое в корень публичного репозитория. Файлы `index.html` и `.nojekyll` должны лежать в корне вместе с папкой `assets`.
2. В репозитории откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**, в **Branch** укажите `main` и `/ (root)`, затем нажмите **Save**.
3. После завершения публикации откройте адрес из раздела **Pages**.

Проект состоит из статических файлов HTML, CSS и JavaScript. Сборка, внешние библиотеки и сервер не требуются. Относительные пути и маршруты с `#/` работают и на адресе вида `https://<owner>.github.io/<repo>/`.

Для локальной проверки запустите `python3 -m http.server 8000` в папке проекта и откройте `http://localhost:8000/`.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Данные и иллюстрации

Названия событий, даты и площадки взяты из опубликованного расписания. Ссылки на расписание доступны в карточках и в `events.js`. Обложки сгенерированы специально для демо и служат редакционными иллюстрациями. Лицензия шрифта Open Sans находится в `assets/open-sans-license.txt`.

Схемы залов, места, цены, платежная карта и почта демонстрационные. Оплата и отправка письма имитируются. Заказы и избранное сохраняются в локальном хранилище текущего браузера.
